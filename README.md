Compile an Individual Program

Example:

g++ -std=c++17 "01_write_text_to_file.cpp" -o program

Run:

./program

Windows:

.\program.exe

Combined File

ALL_16_PROGRAMS_COMBINED.cpp contains the programs together for reference. Because the individual examples may contain separate main() functions, the combined file is intended mainly for study/reference unless the programs are separated or otherwise restructured.

Commented Programs

The Commented_Programs directory contains versions of the programs with explanatory comments, making them useful for learning and revision.

Learning Objectives

After completing Unit IV, you should be able to:

Create and open files.

Read and write text files.

Append information to existing files.

Copy and search files.

Count lines, words, and characters.

Store and search records.

Update file-based records.

Navigate using file pointers.

Work with binary files.

Perform random access.

Handle file errors and stream states.

Build simple file-management applications.

Requirements

C++ compiler such as GCC, Clang, or MSVC.

C++17 or later is recommended.
